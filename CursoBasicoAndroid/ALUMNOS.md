# Alumnos que han completado el curso 🎓

Si has llegado hasta aquí, enhorabuena. Has completado el curso.

Ahora vamos a hacer una última práctica para poner en práctica lo aprendido sobre Git y GitHub.

## ¿Qué tienes que hacer?

1. Haz un **fork** de este repositorio.
2. Clona tu fork en Android Studio.
3. Crea una nueva rama con este formato:

```text
add-nombre-apellido
```

Por ejemplo:

```text
add-aris-guimera
```

4. Añade tu nombre al final de la lista.
5. Haz un commit con este formato:

```text
Add Nombre Apellido
```

6. Haz push de tu rama.
7. Crea una **Pull Request** hacia el repositorio original.

## Reglas

- Añade únicamente tu nombre.
- No borres ni modifiques nombres existentes.
- Una Pull Request por persona.
- Añade tu nombre siguiendo el mismo formato que el resto.
